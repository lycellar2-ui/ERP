# 9.1 Xây dựng Thương hiệu Lyscellar

## 1. Mục đích
- Xây dựng hình ảnh thương hiệu Lyscellar nhất quán, chuyên nghiệp trên mọi kênh.

## 2. Brand Identity

| Yếu tố | Quy định |
|--------|---------|
| **Tên** | Lyscellar (viết liền, chữ L viết hoa) |
| **Tagline** | "Nâng tầm trải nghiệm rượu vang" |
| **Logo** | Logo chính + Logo thu gọn |
| **Màu chính** | Burgundy (#722F37), Gold (#C9A84C) |
| **Màu phụ** | Ivory (#FFFFF0), Dark (#1A1A2E) |
| **Font** | Heading: Playfair Display / Body: Inter |
| **Tone of voice** | Sang trọng, ấm áp, am hiểu, không xa cách |

## 3. Ứng dụng Thương hiệu

| Kênh | Quy cách |
|------|---------|
| **Website** | Màu Burgundy + Gold, ảnh chất lượng cao |
| **Social Media** | Template Canva nhất quán, logo góc |
| **Catalog/Brochure** | Layout chuẩn, giấy cao cấp |
| **Bao bì/Túi giấy** | Logo Lyscellar, chất liệu kraft hoặc matte |
| **Card visit** | Giấy dày, letterpress hoặc gold foil |
| **Xe giao hàng** | Logo + SĐT |

## 4. Quy tắc Sử dụng Logo
- **KHÔNG** kéo giãn, xoay, đổi màu logo
- **KHÔNG** đặt logo trên nền quá rối
- Khoảng cách an toàn: ≥ chiều cao chữ "L" xung quanh
- File gốc: `sources/Brand/Logo/`
