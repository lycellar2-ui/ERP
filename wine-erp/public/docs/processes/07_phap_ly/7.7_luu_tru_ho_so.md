# 7.7 Lưu trữ Hồ sơ & Tài liệu

## 1. Mục đích
- Lưu trữ đầy đủ, có hệ thống tất cả hồ sơ pháp lý, tài chính, mua bán — phục vụ tra cứu, kiểm toán, kiểm tra.

## 2. Cấu trúc Lưu trữ

### 2.1 Hồ sơ Giấy (Physical)

| Loại hồ sơ | Lưu ở đâu | Thời gian lưu | Trách nhiệm |
|-----------|----------|-------------|------------|
| Giấy phép, GPKD | Tủ sắt văn phòng | Vĩnh viễn | BGĐ |
| HĐ ngoại thương | Tủ sắt | ≥ 10 năm | Kế toán |
| B/L, Invoice gốc | Bìa hồ sơ theo lô | ≥ 5 năm | Kế toán |
| Phiếu kiểm nghiệm | Bìa theo SP | ≥ 5 năm | Pháp lý |
| Hóa đơn bán hàng | Bìa theo tháng | ≥ 10 năm | Kế toán |
| PNK, PXK | Bìa theo tháng | ≥ 5 năm | Kho |
| Biên bản kiểm kê | Bìa theo quý | ≥ 5 năm | Kho |

### 2.2 Hồ sơ Số (Digital) — Cấu trúc Thư mục

```
D:\Lyscellar├── Wiki\                          ← Second Brain (Wiki)
├── sources│   ├── Accounting\                ← Sổ kế toán
│   ├── Forms\                     ← Form mẫu Excel
│   ├── Legal│   │   ├── TCB\[NCC]\            ← Các bản tự công bố (deduped, đổi tên theo tên SP)
│   │   ├── Kiem_Nghiem\[SKU]\    ← Phiếu kiểm nghiệm của từng sản phẩm
│   │   ├── Giay_Phep\            ← Scan giấy phép kinh doanh, phân phối rượu
│   │   └── Đường dẫn file TCB - Dịch nhãn - Tem phụ.xlsx  ← File Excel theo dõi TCB Master
│   ├── PO\[NCC]\                 ← Purchase Orders
│   └── Contracts\[NCC]\          ← HĐ phân phối
```

## 4. Backup
- **Hàng tuần:** Backup toàn bộ thư mục `D:\Lyscellar\` ra ổ cứng ngoài
- **Hàng tháng:** Upload lên Cloud (Google Drive / OneDrive)
- **Hồ sơ gốc quan trọng:** Scan và lưu 2 nơi
