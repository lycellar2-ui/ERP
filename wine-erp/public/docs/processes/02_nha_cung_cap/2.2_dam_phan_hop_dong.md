# 2.2 Đàm phán Hợp đồng Phân phối

## 1. Mục đích
- Đàm phán điều khoản hợp đồng phân phối có lợi nhất cho Lyscellar.

## 2. Các Điểm Đàm phán Chính

| Điểm | Mục tiêu Lyscellar | Lưu ý |
|------|-------------------|-------|
| **Giá FOB** | Thấp nhất có thể | So sánh với market rate |
| **Exclusive / Non-exclusive** | Exclusive cho VN | NCC nhỏ dễ đồng ý hơn |
| **MOQ** | Thấp nhất (≤ 300 chai/lần) | Đàm phán giảm cho lần đầu |
| **Payment terms** | TT Trả trước / TT Trả sau | Hạn chế thanh toán trả trước 100% |
| **Incoterm** | FOB (kiểm soát cước) | Xem QT 3.5 |
| **Sample policy** | Free samples | Quan trọng cho mẫu thử |
| **Marketing support** | Ảnh HD, Tasting note, Co-funding | Rất hữu ích |
| **Territory** | Vietnam only (hoặc + Đông Dương) | Rõ ràng |
| **Duration** | 2-3 năm (có gia hạn tự động) | Đừng quá ngắn |

## 3. Quy trình
1. Nhận draft HĐ từ NCC (hoặc gửi template Thắng Ân)
2. Review điều khoản → Đánh dấu cần đàm phán
3. Email/Call đàm phán → Thương lượng từng điểm
4. Đạt đồng thuận → Chuyển [QT 2.3 Ký kết](2.3_ky_ket_hop_dong.md)
