# 2.4 Đánh giá NCC Định kỳ

## 1. Mục đích
- Đánh giá hiệu suất NCC hiện tại hàng năm → quyết định duy trì, mở rộng, hoặc thay thế.

## 2. Tiêu chí Đánh giá (Scorecard)

| Tiêu chí | Trọng số | Điểm (1-5) | Ghi chú |
|----------|---------|-----------|--------|
| Chất lượng rượu | 25% | | Feedback KH, tỷ lệ lỗi |
| Giao hàng đúng hẹn | 20% | | ETA vs Thực tế |
| Giá cạnh tranh | 20% | | So với thị trường |
| Hỗ trợ (docs, mẫu, marketing) | 15% | | Tốc độ phản hồi |
| Flexibility (MOQ, TT) | 10% | | Linh hoạt |
| Doanh số bán được | 10% | | Volume tại VN |

## 3. Phân loại Sau Đánh giá

| Tổng điểm | Phân loại | Hành động |
|-----------|----------|----------|
| ≥ 4.0 | ⭐ Xuất sắc | Mở rộng hợp tác, tăng SL |
| 3.0-3.9 | ✅ Tốt | Duy trì, theo dõi |
| 2.0-2.9 | ⚠️ Cần cải thiện | Thông báo NCC, review lại 6 tháng |
| < 2.0 | 🔴 Kém | Cân nhắc thay thế |

## 4. Quy trình
1. Thu thập data (bán hàng, giao hàng, lỗi, feedback)
2. Chấm điểm theo scorecard
3. BGĐ review kết quả
4. Thông báo NCC (nếu cần cải thiện)
5. Cập nhật vào Wiki entity page
