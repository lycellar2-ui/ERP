# 2.1 Tìm kiếm & Đánh giá NCC Mới

## 1. Mục đích
- Tìm kiếm NCC rượu vang mới phù hợp với chiến lược danh mục của Lyscellar.

## 2. Nguồn Tìm kiếm NCC

| Nguồn | Hiệu quả | Ghi chú |
|-------|---------|--------|
| **Hội chợ** (Vinitaly, ProWein) | ⭐⭐⭐ | Gặp trực tiếp, nếm rượu |
| **Giới thiệu từ NCC hiện tại** | ⭐⭐⭐ | Uy tín, đã được lọc |
| **Wine Magazines** (Decanter, Wine Spectator) | ⭐⭐ | Phát hiện nhà sản xuất mới |
| **Email/Website NCC** | ⭐ | Cold outreach |
| **LinkedIn / Vivino** | ⭐ | Research |

## 3. Tiêu chí Đánh giá NCC

| Tiêu chí | Trọng số | Điểm (1-5) |
|----------|---------|-----------|
| Chất lượng rượu (nếm thử) | 30% | |
| Giá cả (FOB) cạnh tranh | 20% | |
| Khả năng cung cấp (SL, ổn định) | 15% | |
| Chứng nhận (Organic, HACCP...) | 10% | |
| Hỗ trợ marketing (ảnh, tasting note) | 10% | |
| MOQ phù hợp | 10% | |
| Uy tín / Awards | 5% | |

## 4. Quy trình
1. Tìm kiếm NCC → Thu thập catalog, price list
2. Đánh giá sơ bộ theo tiêu chí → Shortlist
3. Yêu cầu mẫu → [QT 2.5](2.5_quan_ly_mau_thu.md)
4. Nếm thử + Đánh giá chất lượng
5. Đàm phán → [QT 2.2](2.2_dam_phan_hop_dong.md)
6. Ký HĐ → [QT 2.3](2.3_ky_ket_hop_dong.md)
