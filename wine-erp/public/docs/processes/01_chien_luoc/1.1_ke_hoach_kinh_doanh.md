# 1.1 Kế hoạch Kinh doanh Năm

## 1. Mục đích
- Lập kế hoạch kinh doanh tổng thể cho năm, bao gồm mục tiêu doanh thu, kế hoạch nhập hàng, phát triển KH, ngân sách.

## 2. Nội dung Kế hoạch

### 2.1 Mục tiêu Doanh thu

| Chỉ tiêu | Năm nay | Năm sau (KH) | % Tăng |
|----------|--------|------------|--------|
| Doanh thu tổng | | | ≥ 20% |
| Số KH hoạt động | | | ≥ 20% |
| Số SKU kinh doanh | | | |
| Biên LN gộp | | | ≥ 35% |

### 2.2 Kế hoạch theo Quý

| Quý | Trọng tâm | Doanh thu KH |
|-----|----------|-------------|
| Q1 (1-3) | Bán hàng sau Tết, phát triển KH mới | 20% |
| Q2 (4-6) | Nhập hàng bổ sung, Event, Mở rộng kênh | 25% |
| Q3 (7-9) | Nhập hàng cho Q4, Training, Chuẩn bị Noel | 20% |
| Q4 (10-12) | MÙA CAO ĐIỂM: Noel, Tết, Corporate Gift | 35% |

## 3. Quy trình Lập kế hoạch
1. **Tháng 11:** Thu thập data năm hiện tại
2. **Tháng 12 tuần 1-2:** BGĐ lập draft kế hoạch
3. **Tháng 12 tuần 3:** Review + Điều chỉnh
4. **Tháng 12 tuần 4:** Finalize + Truyền đạt team

## 4. Review Thực hiện
- **Hàng tháng:** So sánh thực tế vs KH → điều chỉnh nếu cần
- **Hàng quý:** Review sâu → Báo cáo cổ đông
