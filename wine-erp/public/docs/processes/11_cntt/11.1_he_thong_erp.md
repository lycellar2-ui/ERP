# 11.1 Quản lý Hệ thống ERP / Phần mềm
## Mục đích
Vận hành và bảo trì các hệ thống phần mềm quản lý của Lyscellar.

## Hệ thống Hiện tại / Đề xuất
| Chức năng | Phần mềm | Ghi chú |
|-----------|---------|--------|
| Kế toán | MISA / Fast Accounting | Kê khai thuế, hóa đơn điện tử |
| Quản lý Kho | WMS / Excel nâng cao | Tồn kho, FIFO, phiếu xuất nhập |
| CRM | Excel / Phần mềm CRM | Thông tin KH, lịch sử mua hàng |
| Wiki / Knowledge | Obsidian / Markdown | Lyscellar Wiki (Second Brain) |
| Email | Microsoft 365 / Gmail | Giao tiếp NCC, KH |
| Tracking | Website hãng tàu | Theo dõi shipment |

## Lộ trình Nâng cấp
1. **Ngắn hạn:** Chuẩn hóa Excel templates cho Kho, Sales
2. **Trung hạn:** Triển khai phần mềm CRM
3. **Dài hạn:** ERP tích hợp (Kế toán + Kho + Sales)

# 11.2 Quản trị Wiki & Cơ sở Tri thức
## Mục đích
Duy trì và cập nhật Lyscellar Wiki — hệ thống "Second Brain" lưu trữ toàn bộ thông tin sản phẩm, NCC, quy trình, kiến thức rượu vang.

## Cấu trúc Wiki
```
Wiki/
├── index.md          # Mục lục chính
├── wiki/
│   ├── products/     # Trang sản phẩm (theo mã SKU)
│   ├── entities/     # NCC, Khách hàng
│   ├── processes/    # Quy trình (11 nhóm)
│   └── concepts/     # Kiến thức rượu vang
├── sources/          # Tài liệu nguồn (PDF, Excel)
└── claude.md         # Hướng dẫn cho AI Agent
```

## Quy tắc Cập nhật
- Khi nhập NCC mới → Tạo trang NCC + trang sản phẩm
- Khi nhập SP mới → Tạo trang sản phẩm + link tasting note
- Khi thay đổi quy trình → Cập nhật file quy trình + log.md
- Review toàn bộ Wiki: Hàng quý

# 11.4 An ninh Thông tin & Sao lưu
## Chính sách
- Mật khẩu: ≥ 8 ký tự, đổi mỗi 90 ngày
- Phân quyền: Chỉ truy cập dữ liệu theo chức năng
- Sao lưu: Tự động hàng ngày (Cloud + Local)
- Email: Không mở file lạ, cẩn thận phishing
